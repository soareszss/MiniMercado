# Especificação do Trabalho!


Este trabalho consiste no desenvolvimento de um sistema de Mini Mercado utilizando a linguagem Java. O objetivo principal foi criar uma aplicação capaz de gerenciar produtos, clientes e vendas de forma simples e organizada, simulando algumas das operações realizadas em um mercado real.

O programa foi desenvolvido utilizando conceitos de programação orientada a objetos, além da manipulação de arquivos para armazenamento permanente das informações. Dessa forma, os dados cadastrados não são perdidos quando o sistema é encerrado.

Entre as principais funcionalidades implementadas estão o cadastro, consulta, alteração e remoção de produtos. Cada produto possui informações como código, nome, preço e quantidade em estoque. Também foi criado um módulo para gerenciamento de clientes, permitindo cadastrar CPF, nome, telefone e e-mail.

Outra funcionalidade importante do sistema é a realização de compras. Durante uma venda, o usuário informa o CPF do cliente e seleciona os produtos desejados. O sistema calcula automaticamente o valor total da compra, atualiza o estoque dos produtos vendidos e gera uma nota fiscal simples contendo os itens comprados, suas quantidades, subtotais e o valor final da compra.

Para garantir a persistência dos dados, foram utilizados arquivos no formato CSV. Os produtos são armazenados no arquivo "produtos.csv" e os clientes no arquivo "clientes.csv". Sempre que um cadastro é realizado ou alterado, as informações são salvas automaticamente, sendo carregadas novamente quando o programa é iniciado.

De forma geral, este projeto permitiu aplicar conhecimentos importantes de Java, como utilização de classes, objetos, vetores, estruturas de repetição, estruturas de decisão, manipulação de arquivos e interação com o usuário através do console. Além disso, o sistema demonstra na prática como funciona o controle básico de estoque, cadastro de clientes e registro de vendas em um ambiente comercial.
